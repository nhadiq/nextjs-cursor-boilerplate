# Internationalization (i18n) + RTL

## Stack

- [next-intl](https://next-intl.dev/) with `[locale]` routing
- Seed locales: `en` (LTR), `ar` (RTL)

## Adding strings

1. Add key to `messages/en.json`
2. Add matching key to `messages/ar.json`
3. Run `pnpm i18n:check`

## Usage

```tsx
// Server
const t = await getTranslations('auth');

// Client
const t = useTranslations('auth');
```

## RTL CSS

Use logical properties: `ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`, `text-end`.

## Locale switcher

`src/components/layout/locale-switcher.tsx` in app shell header.
